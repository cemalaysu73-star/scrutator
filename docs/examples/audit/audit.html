Methodology

Scrutator asked public sources what they know about the domains in scope: certificate transparency logs, DNS, registration data (RDAP), routing data, web archives and passive-DNS and name aggregators. It did not contact the client's systems except through ordinary DNS lookups.

Every answer was stored unchanged as an evidence record addressed by its SHA-256 hash. Findings and risks are derived from those records by deterministic rules; a risk cannot exist without the records it cites. A name is verified when DNS resolves it or a recent certificate names it, and only claimed when only a list mentions it.

The records, the derived report and a hash-chained log of every lookup were sealed in a proof bundle and signed with an Ed25519 key. The bundle can be checked by anyone, offline, with the commands in the appendix.

Sources used: asn, certspotter, commoncrawl, crtsh, dns, hackertarget, internetdb, mnemonic, rdap, ripestat, subdomaincenter, urlscan, wayback, wildcard.

Glossary

DNS
The internet's directory: it turns names such as www.example.com into addresses.
CNAME (alias)
A DNS record saying a name is another name. If the target disappears, whoever claims it may control the alias.
Subdomain takeover
Taking control of a name whose alias points at a cloud resource that no longer exists.
SPF
A DNS record listing which servers may send e-mail for a domain.
DMARC
A DNS record telling receivers what to do with mail that fails SPF/DKIM checks, and where to report it.
CAA
A DNS record naming the certificate authorities allowed to issue certificates for a domain.
Certificate transparency
Public logs of every TLS certificate issued; they reveal names a company uses.
RDAP
The modern registration database for domains and IP networks (successor of WHOIS).
Verified / claimed
Verified: DNS or a recent certificate supports the name. Claimed: only a list mentions it.
Evidence record
The unchanged answer of a source, identified by its SHA-256 hash.
Proof bundle
A signed file with the report, every evidence record and the lookup log; any change is detected.
SHA-256
A fingerprint of a file: changing one bit changes it completely.
Ed25519
The signature scheme used to seal the bundle; the key fingerprint identifies the signer.
